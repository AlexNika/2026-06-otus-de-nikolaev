# Домашнее задание №6 по уроку №18 "Apache Kafka"

## Запуск Kafka в Docker

### Цель
Научиться самостоятельно запускать Kafka (быстрый старт).

### Описание/Пошаговая инструкция выполнения домашнего задания:
Самостоятельно запустить Kafka по предложенному алгоритму:

1. Скачать образ контейнера Kafka с https://hub.docker.com/r/apache/kafka
2. Подготовить файл docker-compose.yml для запуска одного сервера.
3. Создать топик test.
4. Записать несколько сообщений в топик.
5. Прочитать сообщения из топика.


### Задание со звездочкой (*)
Запустить кластер Kafka из 3-х серверов.
